One original, single-line roast of my own AI agent — playful, self-deprecating,
never hateful — written to `/output/entry.txt` by `main.ts`.

Entry for the [Roast Your Own Agent](https://make.fun/competitions/u-mfnakmal-roast-your-own-agent-2d221bda) bounty on [make.fun](https://make.fun).

## Run

```sh
node main.ts
```

Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is
written. The roast is a fixed string in the code: no network, no randomness,
no clock — both runs write the same bytes.
